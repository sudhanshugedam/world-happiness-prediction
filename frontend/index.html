🤖 About the Project

Project Objective

To develop a Machine Learning system that predicts the happiness score using important explanatory factors from the World Happiness dataset.

  • Dataset preprocessing and cleaning
  • Selection of six explanatory features
  • Regression model training
  • Model evaluation and comparison
  • Happiness score prediction
  • Interactive web dashboard

Machine Learning Workflow

  • 📥 Load World Happiness dataset
  • 🧹 Clean missing observations
  • 🔎 Select six input features
  • ✂️ Split data into training and testing
  • 🧠 Train regression algorithms
  • 📊 Evaluate MAE, RMSE and R²
  • 🏆 Select the best model
  • 🌐 Connect model with web application
